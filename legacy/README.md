# Legacy version

This folder holds the first version of Nearest Essentials Finder: a single
`index.html` page that used the Google Maps JavaScript API and the Places
"search nearby" call straight from the browser.

It had no backend, no database and no saved data. It is kept here for reference
so the history of the project is easy to follow. The current app lives in
[`../backend`](../backend) and [`../frontend`](../frontend).

To try it, put your own Google Maps API key in place of `YOUR_GOOGLE_MAPS_API_KEY`
near the bottom of `index.html` and open the file in a browser.
